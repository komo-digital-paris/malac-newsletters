# Images des newsletters MALAC

Miroir de publication : ces fichiers sont servis en HTTPS pour les
emails, via jsDelivr. Un client mail va chercher les images sans être
connecté — d'où un dépôt public.

    https://cdn.jsdelivr.net/gh/komo-digital-paris/malac-newsletters@main/<dossier>/<fichier>

La source reste le projet iCloud. **Ne jamais réécrire une image déjà
publiée sous le même nom** : jsDelivr la garde en cache plusieurs
heures. Si une image change, changer son nom.
